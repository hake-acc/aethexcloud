AethexCloud — Design Product Requirements Document

Design Philosophy

-   Minimal, timeless, monochrome.
-   Whitespace-first.
-   Every visual element must serve a purpose.
-   Prioritize clarity over decoration.

Brand

-   Name: AethexCloud
-   Tagline: Where Your Ideas Find a Home.
-   Tone: Calm, confident, technical, approachable.

Color System

-   Background: #050505
-   Surface: #0D0D0D
-   Elevated Surface: #151515
-   Card: #111111
-   Primary Text: #FFFFFF
-   Secondary Text: #A1A1AA
-   Muted Text: #71717A
-   Border: rgba(255,255,255,0.08)
-   Hover Border: rgba(255,255,255,0.15)
-   Success: #22C55E
-   Warning: #F59E0B
-   Error: #EF4444
-   Info: #3B82F6

Typography

-   Font Family: Switzer
-   Source: Fontshare
-   H1: 64px / 700 / 1.05 / -0.04em
-   H2: 48px / 600
-   H3: 36px / 600
-   Body: 18px / 400 / 1.6
-   Button: 16px / 500

Layout

-   8px spacing system
-   Max container: 1440px
-   Content width: 1280px
-   12-column grid
-   32px column gap
-   Mobile-first responsive design

Border Radius

-   Buttons: 16px
-   Inputs: 16px
-   Cards: 24px
-   Sections: 32px

Icons

-   Library: @tabler/icons-react
-   Stroke: 1.5
-   Default: 24px
-   Color: currentColor
-   Never mix UI icon libraries.

3D Illustration Style

-   Custom Blender-style assets
-   Rounded geometry
-   Soft lighting
-   Smooth surfaces
-   Transparent background
-   WebP preferred
-   White and black variants

Components

-   Sticky navigation
-   Mega menu
-   Hero
-   Feature cards
-   Pricing cards
-   Testimonials
-   FAQ
-   Footer
-   Forms
-   Tables
-   Badges
-   Toasts
-   Modals

Motion

-   GSAP
-   Smooth page transitions
-   Scroll reveals
-   Hover lift
-   Magnetic buttons
-   power3.out easing
-   Performance first

Accessibility

-   WCAG AA
-   Semantic HTML
-   Keyboard navigation
-   Visible focus states
-   Proper heading hierarchy

Non-Negotiable Rules

-   No gradients
-   No glassmorphism
-   No neumorphism
-   No stock illustrations
-   No emojis in UI
-   Consistent spacing
-   Consistent border radius
-   Reusable components only
-   Responsive by default
-   Minimal dependencies
