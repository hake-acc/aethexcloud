AethexCloud — Technical Product Requirements Document (Technical PRD)

1. Project Overview

-   Project Name: AethexCloud
-   Project Type: Premium Cloud Hosting Platform
-   Application Type: Full Stack Web Application
-   Primary Platform: Web
-   Architecture: Next.js App Router

2. Core Technology

-   Framework: Next.js (Latest Stable)
-   Frontend: React (Latest Stable)
-   Language: TypeScript
-   Runtime: Node.js LTS
-   Package Manager: pnpm
-   Deployment: Vercel

3. Styling

-   Tailwind CSS
-   Utility-first architecture
-   No CSS frameworks besides Tailwind
-   Avoid inline styles unless required
-   Reusable component styling
-   No !important
-   No duplicated utility patterns

4. Typography

-   Font: Switzer
-   Source: Fontshare
-   Loading: Next.js Font Optimization
-   Fallback: system-ui, sans-serif

5. Icons

-   Library: @tabler/icons-react
-   Stroke: 1.5
-   Default Size: 24px
-   Small: 20px
-   Large: 32px
-   Color: currentColor
-   Never mix icon libraries

6. Animation

-   GSAP
-   Smooth, purposeful animations
-   Hardware accelerated transforms
-   Prefer transforms over layout changes

7. Images

-   next/image
-   Blender-style 3D assets
-   Rounded geometry
-   Transparent background
-   WebP preferred, PNG when needed

8. Code Standards

-   TypeScript Strict
-   Reusable components
-   No duplicated code
-   Composition over inheritance
-   Consistent naming
-   Avoid any where possible
